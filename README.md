# Make Knowledge Cards

把文章变成可以真正复习的知识卡片。

## 项目解决什么问题

长文章的信息密度高，收藏、划线或写一篇长摘要都不等于能复习。这个项目把一篇文章压缩成少量、原子化、可独立复习的卡片，并让每张卡都回到原文，解决三个常见问题：摘要太长、卡片太碎、内容被改写或编造。

## 主要功能

- **输入**：支持直接粘贴正文，或读取本地 `.md` / `.txt` 文件；完整读取后处理，一次处理一份输入。
- **数量控制**：目标生成 5–8 张卡片。候选超过 8 个时取最重要的 8 个或合并高度相关的点；合格知识点不足 5 个时按实际数量输出并注明“原文信息有限”，不拆分、重复或补写来凑数；没有实质知识时说明原因并停止。
- **卡片结构**：每张卡片包含标题、核心知识、简明解释，以及原文中的例子或一道附简短答案的自测题。
- **知识提炼**：优先保留定义、核心主张、因果机制、方法步骤和判断标准；合并重复表述，删除跨卡重复的细节、例子和提醒，保证一张卡只讲一个知识点。
- **原文忠实**：不补充原文没有的事实、因果、细节、比较或例子；保留原文的限定词；原文是观点时明确写成“作者认为/主张”。
- **默认输出**：只输出知识卡片，不附加全文摘要、评价、学习计划或扩展知识。

## 项目结构

```text
README.md
skills/
└── make-knowledge-cards/
    ├── SKILL.md
    └── agents/
        └── openai.yaml
```

Skill 由纯指令构成，不需要额外脚本或依赖。

## 安装

将 Skill 目录复制到 Codex 的 skills 目录：

```bash
mkdir -p "${CODEX_HOME:-$HOME/.codex}/skills"
cp -r skills/make-knowledge-cards "${CODEX_HOME:-$HOME/.codex}/skills/"
```

Windows 上也可以手动把整个 `skills/make-knowledge-cards` 文件夹复制到 `%USERPROFILE%\.codex\skills\`。

重新加载 Codex 后，通过 `$make-knowledge-cards` 调用。

## 使用方法

直接粘贴文章：

```text
$make-knowledge-cards
把下面这篇文章整理成知识卡片：

<粘贴文章正文>
```

处理本地文件：

```text
$make-knowledge-cards 请把 ./notes/sleep.md 整理成知识卡片。
```

一次处理一份输入；如果提供多份文件，请先指定要处理的那一份。

## 输入输出示例

输入：

```text
间隔重复的关键不是把同一内容连续看很多遍，而是在快要忘记时再次接触。
每次回忆都会让记忆更牢固。把复习安排在逐渐拉长的时间点上，比临时突击更有效。
```

输出：

```markdown
原文信息有限，仅生成 3 张卡片。

### 1. 间隔重复要在“快要忘记时”进行

**核心知识：** 间隔重复不是把同一内容连续看很多遍，而是在快要忘记时再次接触。

**简明解释：** 原文把“快要忘记时”作为再次接触的时机，并明确区分于连续重复。

### 2. 回忆会让记忆更牢固

**核心知识：** 每次回忆都会让记忆更牢固。

**简明解释：** 原文把“回忆”本身视为增强记忆的环节。

**自测：** 按照原文，增强记忆的环节是什么？

**答案：** 每次回忆。

### 3. 复习间隔要逐渐拉长

**核心知识：** 把复习安排在逐渐拉长的时间点上，比临时突击更有效。

**简明解释：** 原文直接把“逐渐拉长的间隔”与“临时突击”作了效果比较。
```

这个例子使用的是一篇只有 3 个合格知识点的短文，所以输出 3 张并注明信息有限，没有强行补到 5 张。信息充足时，默认输出 5–8 张。

## 支持范围

支持：

- 直接粘贴的正文
- 本地 `.md`、`.txt` 文件

暂不支持：

- 网页抓取或 URL 解析
- PDF
- Anki 导出
- 图形界面

遇到不支持的形式时，请先粘贴正文，或提供 `.md` / `.txt` 文件。
